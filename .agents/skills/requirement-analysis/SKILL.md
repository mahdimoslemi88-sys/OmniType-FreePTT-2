# Requirement Analysis Skill

## هدف مهارت
تحلیل ساختارمند نیازمندی‌های صنعتی، استخراج فرآیندهای کسب‌وکار، و تبدیل شرح نیازمندی به مشخصات دقیق مهندسی در سامانه ارجاع آتبین ایستا.

## مراحل اجرا (Procedure)
1. **بررسی ورودی‌ها:** مطالعه استعلام‌های نمونه، پرسشنامه‌ها و کاتالوگ محصولات.
2. **استخراج ذینفعان و نقش‌ها:** مدیر بازاریابی، مدیران واحدهای فنی ۶ گانه (گسکت، نسوز، توربو، پایپینگ، حفاظت کاتدیک، کارگاه)، اپراتور اداری.
3. **تفکیک نیازمندی‌های کارکردی و غیرکارکردی:**
   - کارکردی: استخراج اقلام، تفکیک استعلام چندقلمی، تشخیص استاندارد ASME/API، اتصال به CRM.
   - غیرکارکردی: زمان پاسخگویی زیر ۱۰ ثانیه، حفظ محرمانگی پتروشیمی‌ها، امکان اجرای آفلاین/محلی.
4. **نگاشت به User Stories:**
   - قالب: «به عنوان [نقش] می‌خواهم [قابلیت] تا بتوانم [ارزش تجاری]».
5. **تعیین معیارهای پذیرش (Acceptance Criteria):** بر مبنای تست‌های شفاف و قابل اندازه‌گیری.
