# Model Management Skill (مهارت مدیریت چرخه حیات مدل‌های هوش مصنوعی)

## هدف مهارت
این مهارت راهنمای جامع مدیریت و نظارت بر مدل‌های یادگیری ماشین و پردازش زبان طبیعی (LLM / SLM) در سامانه هوشمند ارجاع آتبین ایستا است.

## گردش کار مهارت (Workflow)
1. **شناسایی و فرموله‌سازی نیاز به مدل:**
   - تعیین نوع تسک (طبقه‌بندی چندلایه، ماسک‌سازی PII، امبدینگ، یا OCR).
2. **انتخاب شماره یکتا برای MDR:**
   - بررسی پوشه `docs/MDR/` و ایجاد سند جدید بر مبنای `.agents/templates/MDR-template.md`.
3. **ارزیابی تطبیق‌پذیری سخت‌افزاری:**
   - سنجش محدودیت‌های سرور HP ProLiant DL380 G8 (فاقد GPU و دارای ۳۲ گیگابایت رم).
   - انتخاب متد کوانتیزاسیون (GGUF Q4_K_M / AWQ / ONNX) در صورت اجرای محلی.
4. **اجرای بنچ‌مارک روی مجموعه آزمون مرجع:**
   - سنجش عملکرد روی `data/dataset_sample_1000.csv` با معیار اجباری Macro-F1.
5. **مدیریت مخزن پرامپت‌ها و بانک چندباره (Few-Shot):**
   - نگهداری نسخه‌های پرامپت در `docs/ai/prompts/` با ثبت ساختار JSON خروجی.
6. **پایش رانش مدل (Drift Monitoring):**
   - سنجش پیوسته توزیع کلاس‌های پیش‌بینی‌شده و مقایسه با داده‌های تاریخی.
