# Documentation Standard Skill

## هدف مهارت
حفظ یکپارچگی، زیبایی بصری، خوانایی، و استانداردهای نگارشی کلیه اسناد فنی و متون گزارش‌های پروژه آتبین ایستا.

## ضوابط و الزامات فرمت‌بندی
1. **زبان و نگارش فارسی:** استفاده از نیم‌فاصله استاندارد، رسم‌الخط مصوب فرهنگستان، و جلوگیری کامل از شکستگی یا وارونگی کلمات.
2. **لینک‌های معتبر گیت‌هاب:** تمام ارجاعات به فایل‌ها باید به صورت پیوند معتبر مارک‌داون باشد: `[عنوان](file:///path/to/file)`.
3. **جعبه‌های هشدار گیتهاب (Alerts):** استفاده مناسب از `> [!NOTE]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!CAUTION]`.
4. **دیاگرام‌های Mermaid:** ترسیم جریان‌ها و معماری به روش نمودارهای متنی Mermaid با نام‌گذاری‌های دقیق.
5. **همگامی با ایندکس مرکزی:** ثبت فوری هر سند جدید در جدول یا فهرست مرتبط در `docs/INDEX.md`.
