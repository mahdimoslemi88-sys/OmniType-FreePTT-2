# Rule 04: Security & Confidentiality Policy (قانون امنیت و محرمانگی داده‌ها)
**Scope:** All Agents & Infrastructure Operations  
**Authority:** Security Reviewer  

---

## 1. محرمانگی اسناد صنعتی نفت و گاز
ایمیل‌ها و استعلام‌های شرکت آتبین ایستا حاوی اسناد محرمانه مجتمع‌های پتروشیمی، مبالغ مالی، شماره استعلام‌های مناقصات و اطلاعات اشخاص است.

## 2. الزامات امنیتی فنی
1. **عدم افشای کلیدها و اعتبارسنجی‌ها (Secrets Zero Leakage):** هیچ کلید API، کلمه عبور ایمیل، یا توکن دسترسی نباید در کد منبع یا فایل‌های Git ذخیره شود. همواره از متغیرهای محیطی (`.env` خارج از ورژن کنترل) استفاده شود.
2. **ماسک‌گذاری داده‌های حساس (PII / Commercial Anonymization):**
   - پیش از ارسال متن استعلام‌ها به هرگونه سرویس خارجی، نام افراد، شماره تماس‌های شخصی و مبالغ پیشنهادی باید توسط ماژول Sanitize محلی ماسک گردند.
3. **کنترل دسترسی APIها:** ارتباط با Web API نرم‌افزار Sarv CRM باید از طریق کانال‌های رمزگذاری‌شده HTTPS و توکن‌های دارای انقضا صورت گیرد.
4. **عدم اجرای اسکریپت‌های ناشناخته پیوست‌ها:** پیوست‌های دریافتی از مشتریان تا زمان بررسی نوع فایل و اعتبارسنجی فرمت، هرگز نباید به صورت محلی Execute شوند (خطر فایل‌های ماکرو یا بدافزار).
