# دفتر مشاهدهٔ رفتار ASR در اپ‌های ChatGPT و Gemini

این فایل را همراه با `observe-asr.ps1` پر کنید. برای هر جلسهٔ دیکته یک بلوک
«جلسه» بسازید و مشاهدات مستقیم را با ارجاع به فایل JSONL ثبت کنید.

> **قاعده:** هر ادعا باید به یک ردیف با timestamp در `logs\*.jsonl` ارجاع بدهد.
> «به نظر می‌رسد» معیار قبولی نیست.

---

## اسکیمای لاگ (JSONL)

هر خط یک شیء JSON است. `type` تعیین می‌کند بقیهٔ فیلدها چه معنایی دارند:

| `type` | فیلدها | معنی |
| --- | --- | --- |
| `session_start` | `apps[]`, `intervalMs`, `durationSec`, `uia`, `host`, `user` | شروع ضبط |
| `target_inventory` | `pid`, `name`, `wsMB`, `modules[]`, `cdpFlag`, `cdpVersion`, `cmdLine` | یک‌بار در شروع، برای هر پروسهٔ هدف |
| `cdp_open` | `port`, `version` | یک پورت دیباگ باز روی سیستم پیدا شد |
| `snapshot` | `tick`, `foreground{pid,process,title}`, `processes[]`, `mic{}`, `connections[]`, `newText{}`, `tickMs` | نمونهٔ دوره‌ای |
| `marker` | `note` | کاربر Enter زد |
| `session_end` | `ticks` | پایان |

فیلدهای مهم داخل `snapshot`:
- `mic` — کلید = مسیر اپ؛ `inUse: true` یعنی **همین حالا** اپ میکروفون را گرفته.
- `connections` — `remote`, `state`, `rdns`, `vendor`. اگر هنگام گفتار یک
  کانکشن تازه به Google/OpenAI ظاهر شود، یعنی STT ابری است.
- `newText` — فقط وقتی متن کادر ورودی هدف **تغییر** کند نوشته می‌شود.

## چک‌لیست فرضیه‌ها

### H1 — آیا اپ صدا را به ابر می‌فرستد یا محلی پردازش می‌کند؟
- [ ] `target_inventory.modules` شامل `whisper|onnx|ggml|vosk|sherpa` بود؟ (اگر نه → محلی نیست)
- [ ] هنگام گفتار، `connections` به `*.google.com` / `*.openai.com` ظاهر شد؟
- **نتیجه:** _(پر شود)_

### H2 — چه موقع دقیقاً میکروفون را می‌گیرد و رها می‌کند؟
- [ ] `mic[...].start` با لحظهٔ کلیک روی دکمهٔ میکروفون هم‌زمان است؟
- [ ] `inUse` بعد از توقف گفتار به `false` برمی‌گردد؟ چقدر طول می‌کشد؟
- **نتیجه:** _(پر شود)_

### H3 — آیا می‌توان متن را بدون تزریق کیبورد برداشت کرد؟
- [ ] با فلگ `--force-renderer-accessibility`، `newText` پر شد؟ (بدون فلگ: خالی)
- [ ] با CDP (`Runtime.evaluate`) متن کادر قابل خواندن بود؟
- **نتیجه:** _(پر شود)_

### H4 — تاخیر انتها به انتها چقدر است؟
- [ ] از `marker` (رها کردن کلید) تا اولین `newText` چند میلی‌ثانیه؟
- **نتیجه:** _(پر شود)_

### H5 — آیا می‌توان پورت دیباگ را روشن کرد؟
- [ ] `cdpFlag` بعد از اجرا با `--remote-debugging-port` مقدار گرفت؟
- [ ] `cdp_open` برای ۹۳۳۳/۹۳۳۴/۹۳۳۵ ثبت شد؟
- **نتیجه:** _(پر شود)_
