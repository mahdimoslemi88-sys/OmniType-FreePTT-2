# چک‌لیست تیون بصری تم روشن (light-theme)

بیلد ریلیز آماده است. مقادیر روشن در `src/gui/overlay.rs` → `palette::light` یک مبنا
هستند؛ این چک‌لیست تأیید **چشمی** روی ویندوز واقعی را پوشش می‌دهد (کامپایل و تست هر دو
تم ۹۷/۹۷ سبز است).

## ساخت بیلدها

```bash
cd v-2/voice-ptt
cargo build --release --features light-theme   # → target/release/voice-ptt.exe (روشن)
cargo build --release                          # → تاریک (بیلد عادی)
```

نسخهٔ تاریک فعلی برای مقایسهٔ A/B کنار گذاشته شده: `/tmp/voice-ptt-dark.exe`
(هر دو نسخه را **هم‌زمان اجرا نکنید** — بر کلید میان‌بر و میکروفون نزاع می‌کنند).

## چک‌لیست چشمی (به ترتیب صفحه)

### کپسول ضبط (۴ حالت + خط خفته)

- [ ] **IdleDormant** — خط ۳۶×۵ بالای تسک‌بار روی تسک‌بار **روشن** ویندوز دیده می‌شود؟ (روشن‌تنظیم شده؛ اگر گم شد، `DORMANT_BAR` را تیره‌تر نکنید — موقعیت/سایه را ببینید)
- [ ] **HoveredAwake** — پیل میکروفون + tooltip «Dictate CapsLock»: پیل با `MIC_IDLE` تینت روشن از پس‌زمینهٔ روشن دسکتاپ جدا هست؟ متن بج با `BADGE_TEXT` خواناست؟
- [ ] **RecordingActive** — قرمزها (`REC_TEXT`, `WAVE_STRONG`, `CANCEL_ICON`) خوانا؟ موج از `WAVE_FAINT` تا `WAVE_STRONG` گرادیان محسوس دارد؟
- [ ] **Processing** — هالهٔ کهربایی `PROC_GLOW` و متن `PROC_TEXT` تمایز با حالت ضبط دارد؟
- [ ] **Error** — `DANGER` روی سطح روشن به‌اندازهٔ تم تاریک هشداردهنده است؟
- [ ] گوشه‌های گرد DWM و شفافیت ویوپورت روی هر دو تم یکسان‌اند؟ (بدون تغییر — فقط تأیید)

### توست‌ها (پیش‌نمایش متن)

- [ ] کارت `TOAST_BG` روشن روی دسکتاپ روشن (والپیپر روشن امتحان کنید) لبهٔ واضح دارد؟ — کارت شناور است، پس «هالهٔ» تاریکِ تم تاریک را ندارد
- [ ] کپشن با `TEXT_PRIMARY` (۱۵٫۶×) و فوتر شمارش معکوس خواناست؟
- [ ] آیکون میکروفون با `ACCENT` (۴٫۵× روی روشن) به‌چشم می‌آید؟
- [ ] نوار پیشرفت و ضربدر ✕ (رنگ متن) روی کارت روشن مرئی‌اند؟
- [ ] کپ عرض ۳۲۰px: متن بلند/URL به‌جای کشیدگی افقی، عمودی می‌شکند؟ (ویژگی جدید وندور — در هر دو تم یکسان است)
- [ ] دو کارت سه‌خطی روی هم داخل ارتفاع میزبان ۱۹۰px جا می‌شوند؟

### پنجرهٔ دیکشنری

- [ ] عنوان/زیرنویس/بج شمارنده با پیل‌های `HEADER_PILL_BG` هم‌خانواده‌اند؟
- [ ] کارت افزودن کلمه (`manager_card`): خط `CARD_STROKE` روی `CARD_BG_ALT` مرئی ولی مزاحم نیست؟
- [ ] داخل TextEdit (`extreme_bg_color = CARD_BG_ALT`) با متن تیره خواناست؟
- [ ] حالت hover دکمه‌ها (`HEADER_PILL_BG`) از حالت عادی (`CHIP_BG`) قابل تشخیص؟
- [ ] ردیف‌های جدول و رنگ `TEXT_TABLE` در کنتراست متن ردیف؟

### پنجرهٔ موتور

- [ ] ردیف انتخاب‌شده (`AUTO_BG` + `SELECT_STROKE`) و ردیف عادی تفکیک‌پذیر؟
- [ ] بج وضعیت موتور: `SUCCESS_DOT`/`DOT_INACTIVE` و متن چیپ `SUCCESS_CHIPTXT` خوانا؟
- [ ] دکمهٔ آبی اقدام (`ACCENT_ACTION` ۵٫۵×) برجسته‌ترین عنصر صفحه است؟
- [ ] بنر موفقیت: جفت `SUCCESS / SUCCESS_FILL` (۳٫۳×) — اگر کم‌جان بود، پیشنهاد جدول بالا
- [ ] متن حذف‌شدنی‌ها با `DANGER_SOFT` قابل تشخیص ولی بی‌سروصدا؟

### پنجرهٔ تاریخچه

- [ ] کارت‌های `CARD_TRANSLUCENT` با خط `HAIRLINE` از پس‌زمینه جدا می‌شوند؟ (در تم روشن هر دو تقریباً هم‌رنگ‌اند — مشکوک‌ترین آیتم چک‌لیست)
- [ ] متن رکورد/زمان/موتور با سلسله‌مراتب `TEXT_PRIMARY → TEXT_FAINT` خواناست؟

### ویجت‌های استوک egui (`apply_theme_visuals`)

- [ ] اسکرول‌بار، جداکننده و رنگ انتخاب متن (`selection = SELECT_STROKE`) در هر سه پنجره تم‌شده‌اند؟
- [ ] چیزی با رنگ پیش‌فرض تاریک egui باقی نمانده؟ (به‌ویژه tooltip ها)

### مقایسهٔ A/B

- [ ] یک متن ضبط‌شدهٔ واقعی را در هر دو بیلد ضبط کنید؛ توست، کپسول و هر سه پنجره را پشت‌سرهم مقایسه کنید — «حس» خانوادگی باید حفظ شده باشد، نه تبدیل به دو برنامهٔ متفاوت

## اگر چیزی خواست تغییر کند

همه‌چیز یک‌خطی در `palette::light` است (خطوط ~۱۸۶–۲۸۰ `src/gui/overlay.rs`)؛ نام نقش‌ها
با تم تاریک یکی است و هیچ call-site تم را نمی‌شناسد. بعد از هر تغییر:

```bash
cargo clippy --all-targets --features light-theme && cargo test --lib --features light-theme
cargo build --release --features light-theme
```

نکته: مقادیر پیشنهادی جدول «زیر آستانه» را فقط بعد از تأیید چشمی اعمال کنید —
عددِ کنتراست جای قضاوت چشمی را نمی‌گیرد.
