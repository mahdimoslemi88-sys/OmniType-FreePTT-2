## بخش ۲: گزینه‌های طراحی ساختار تب‌دار

> تغییر substantial → حداقل دو گزینه (بخش ۲ اسکیل)

### گزینه الف — Unified Dashboard (تب‌های درون‌پنجره‌ای) ⭐ توصیه‌شده

**ایده:** یک پنجره اصلی واحد `OmniType Dashboard` با `egui::TabBar` که همه نماها رو در بر می‌گیره. کپسول شناور (overlay) دست‌نخورده باقی می‌مونه.

```
┌─────────────────────────────────────────────────────┐
│  OmniType                    [─] [□] [×]            │
├─────────────────────────────────────────────────────┤
│  [ موتورها ] [ دیکشنری ] [ تاریخچه ] [ تنظیمات ]    │
├─────────────────────────────────────────────────────┤
│                                                     │
│   ┌───────────────────────────────────────────┐     │
│   │  کارت محتوای تب فعال                      │     │
│   │  (همون manager_card های موجود)             │     │
│   └───────────────────────────────────────────┘     │
│                                                     │
│        ─── اسکرول عمودی برای همه تب‌ها ───          │
│                                                     │
├─────────────────────────────────────────────────────┤
│  ● آماده  │  ویسپر محلی  │  نسخه ۰.۱               │  ← نوار وضعیت
└─────────────────────────────────────────────────────┘
```

**ساختار فنی:**
- فیلد جدید: `show_dashboard: bool` + `dashboard_tab: DashboardTab` (enum با ۴ variant)
- ترَی منوی `Open OmniType` → `show_dashboard = true` (به جای toggle کپسول)
- کپسول شناور فعلی کاملاً حفظ میشه (IdleDormant / Recording / Processing)
- ۴ تابع `render_*_window` موجود → به `render_*_tab(&mut self, ui)` تبدیل میشن (بدون viewport wrapper)
- `egui::ScrollArea::vertical()` دور کل تب فعال
- نوار وضعیت پایین: state + engine + first-run cue

**مزیت:** یکپارچه، کم‌ریسک (چون منطق موجود reuse میشه)، اسکرول یکپارچه
**عیب:** کپسول و داشبورد دو نقطه نمایش دارن (ولی این دقیقاً مدل Wispr Flow هست)

## بخش ۳: فیکس باگ‌ها (مستقل از گزینه ساختار)

این موارد فارغ از انتخاب ساختار، حتماً انجام میشن:

### ۳-۱: فیکس فلیکر پیش‌نمایش

**روش:** اضافه کردن `set_caption` به `Toast` در `third_party/egui-notify` (vendored، مجاز):

```rust
// third_party/egui-notify/src/toast.rs
pub fn set_caption(&mut self, caption: impl Into<String>) -> &mut Self {
    self.caption = caption.into();
    self
}
```

و در `refresh_toast_countdowns` به جای `add + dismiss_oldest`، مستقیماً caption همون toast رو آپدیت کنیم:

```rust
// قبل: add toast جدید + dismiss_oldest → فلیکر
// بعد: پیدا کردن toast زنده با seq، set_caption → بدون rebuild
```

**نتیجه:** countdown تیک می‌زنه ولی پنجره هیچ‌وقت rebuild نمیشه.

### ۳-۲: فیکس چسبیدن به گوشه

اضافه کردن `with_position()` به همه viewport‌ها، center شده روی صفحه:

```rust
let screen = ctx.screen_rect();
let (w, h) = (580.0, 620.0);
ViewportBuilder::default()
    .with_position([
        (screen.center().x - w / 2.0).round(),
        (screen.center().y - h / 2.0).round(),
    ])
    .with_inner_size([w, h])
```

### ۳-۳: فیکس اسکرول

دور کردن کل محتوای هر manager با:

```rust
egui::ScrollArea::vertical()
    .auto_shrink([false, false])
    .show(ui, |ui| {
        // همه کارت‌ها
    });
```
